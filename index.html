01 / PROYECTO PERSONAL

Zireba

Aplicación orientada a facilitar la organización y el seguimiento del cuidado de mascotas.

PHP MySQL HTML CSS

¿En qué consiste?

Zireba es un proyecto personal de desarrollo de una aplicación web que busca simplificar la gestión del cuidado de las mascotas mediante un entorno digital en el que centralizar su información.

Objetivo del proyecto

Crear una herramienta intuitiva que permita organizar la información de cada mascota y establecer una base para incorporar nuevas funcionalidades relacionadas con su cuidado.

Desarrollo y tecnologías

El proyecto se desarrolla utilizando PHP y MySQL, trabajando tanto en la lógica de la aplicación como en el diseño y la gestión de la base de datos.

Trabajo realizado

Análisis y planificación de requisitos, diseño de la identidad visual y experiencia de usuario, desarrollo de la aplicación web, estructuración de la base de datos y documentación del proyecto.

Estado del proyecto

V1 desarrollada: base funcional de la aplicación sobre la que se continuará trabajando para incorporar nuevas funcionalidades.

02 / PROYECTO PERSONAL

Lumo

Plataforma de organización académica diseñada para centralizar tareas, planificación y objetivos.

Python

¿En qué consiste?

Lumo es un proyecto personal de desarrollo de una plataforma web orientada a mejorar la organización académica. Nació de la necesidad de reunir en un mismo espacio herramientas que faciliten la planificación del estudio y la gestión de las actividades académicas.

Objetivo del proyecto

Crear un entorno digital sencillo e intuitivo que permita organizar las tareas, asignaturas, exámenes y objetivos académicos.

V1 – Funcionalidades iniciales

La primera versión establece la base de la plataforma e incluye herramientas para organizar exámenes, entregas y fechas importantes, gestionar tareas pendientes, centralizar información de asignaturas y realizar un seguimiento de la actividad académica.

V2 – Evolución del proyecto

La segunda versión plantea ampliar la plataforma mediante el desarrollo de su identidad de marca, creación de contenido y estrategias de comunicación digital. También contempla nuevas funcionalidades como recordatorios, objetivos semanales y un temporizador para registrar el tiempo de estudio.

Trabajo realizado

Diseño y planificación del proyecto, organización de funcionalidades, desarrollo de la aplicación, diseño de la base de datos y evolución de su identidad digital.
